# Zelda Princess Desktop Pet

Assets and validation records for the Zelda Princess Codex desktop pet.

## Contents

- `pet.json` — pet metadata and sprite configuration
- `spritesheet.png` / `spritesheet.webp` — v2 sprite assets
- `validation-v2-final.json` — final validation report
- `chroma-*.json` — chroma/despill processing records
- `hermes-link-concept-v1.png` — related Link concept preview

## Status

The sprite package is preserved from the completed local v2 validation run.
The Link concept image is a preview asset and is not part of the deployed pet.
